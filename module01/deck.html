       /// RESTRAINT                                                                                          
                                                                                                              
       WHEN NOT TO BUILD AN AGENT                                                   
                                                                                                              
                                                                                                              
                                                                                                              
                                                                                                              
       ✘ The steps are always the same. That is a function. Write the function.                               
                                                                                                              
       ✘ You need the same output every time. Agents are non-deterministic by construction.                   
                                                                                                              
       ✘ A wrong action is expensive or irreversible. Money moved, emails sent, rows deleted.                 
                                                                                                              
       ✘ Latency budget is under a second. An agent loop is 3–30+ model calls.                                
                                                                                                              
       ✘ You cannot describe success. If you cannot write the eval, you cannot ship the agent.
